# 目标选择 UI 验收

2026-09-14，已集成到本地项目。

## 行为

- 魔法目标面板显示来源卡、目标范围、合法数量和明确的选中状态。候选可从面板或场上点击；仍由原规则校验并确认结算。
- 余烁归轨只列出合法墓地怪兽，显示隐藏的不合格卡数量。候选和详情使用基础卡数据，不带墓地里残留的强化、守备或已行动状态。
- 碎月解幕只突出敌方有卡的合法卡槽，直接显示公开卡名与卡位；其他卡槽弱化。盖牌只显示“盖放卡牌”和位置。
- 唯一目标明确提示已默认选择；多个目标需主动点选，可切换后再确认。取消不会消耗卡牌。
- 攻击选择显示“点击攻击”，空位与魔陷区弱化。墓地选择不再提示去场上找目标。
- 候选列表与确认按钮集中在手牌区域；手机横屏使用右侧面板，长列表可滚动。详情浮层高于顶栏及目标面板。

## 手牌排序后的可用状态

手牌高亮、操作标签和不可用原因按卡牌 UID 找回规则手牌中的实际位置，不能用显示序号查询规则；点击发动也使用同一卡牌身份。拖动、按类型整理、抽牌和移除卡牌都不应改变其他卡牌原本的合法性。余烁归轨有合法墓地怪兽且满足发动条件时亮起，没有目标时保留具体原因。

回归入口 `?test=1&smoke=hand-action-order` 使用终局三曜完整对局，验证无目标／有目标时整理顺序、手动微调、手牌增减后高亮和原因不变，最后发动余烁归轨确认结果。
