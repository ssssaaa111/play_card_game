# 对手行动自动播放

普通公开行动不再弹出遮罩或要求点击继续。行动栏复用顶部状态区，展示期间暂时替代回合信息和操作按钮，设置入口保持可用，展示结束后恢复。战场和手牌的位置、可用空间不变，玩家仍可看见、整理手牌。行动栏展示行动名称、实际结算摘要及自动进度；场上来源及受到影响的卡牌、生命面板显示对应标记。对手盖牌和抽到的卡牌身份不进入行动摘要。

- 普通召唤、魔法展示 1.6 秒；王牌召唤 2.1 秒；陷阱和攻击后效果 2.2 秒。召唤、魔法后的旧额外等待缩短为 0.25 秒，避免重复等待。
- “查看详情”、页面切到后台、暂停播放和主动回看都会暂停推进；关闭详情或返回对局后继续。快进只跳过当前展示。
- 真实的陷阱响应、连锁和目标选择仍使用原有选择流程。攻击后追加伤害沿用已有 HUD 暂存，结果展示结束后再显示最终 LP。
- 手牌工具栏的回看入口在顶部展开最近三步，保留行动当时的结果摘要；卡牌完整说明通过统一详情打开，返回对局后恢复当前播报。更早的记录仍在原有对战记录内。
- 重开时清空当前展示、队列与历史，取消旧计时；AI 回合的异步步骤检查对局编号。

主要代码：`src/ai-action-playback.js`、`src/app.js`、`ai-action.css`。播放控制器只管理展示，不修改规则状态。

回归入口：`?test=1&smoke=ai-card-reveal-queue` 验证两步自动连播、阅读详情期间暂停、手牌位置不变且可接收指针输入、战场不被裁切和播报／设置按钮可点击；`?test=1&smoke=ai-card-reveal-confirm` 验证真实玩家响应优先与详情入口。手动场景 `trioLiveTurnReplanning` 可观察分裂、召唤、强化连续播放，`protagonistTrioOmega` 可验证日冕诱锁的实际响应操作。
