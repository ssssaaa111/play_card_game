# 第 1 轮可玩性验收

日期：2026-11-07。基于主线 `50f1616`，本轮聚焦卡组编辑与已有对局交互，不扩展联机规则或调整卡牌强度。

## 已复现并修复

1. 卡组编辑器的全部 35 张怪兽摘要显示 `ATK undefined / DEF undefined`。原因是读取了旧字段 `attack/defense`；已统一读取卡牌定义的基础值 `atk/def`。
2. 390px 手机竖屏中，预设下拉框的固定最小宽度挤出了导入按钮，名称输入框也超出工具栏。窄屏导入区改为两行网格，表单项允许收缩，保持现有战场布局。
3. 选择「速攻炎风」后修改卡组名，预设会重置为「均衡星魂」。原因是每次编辑重新生成选项，丢失已选值；现保留仍然有效的预设选择。

## 真实页面操作

### 内置浏览器：卡组与响应式

- 390×844：打开编辑器，导入均衡预设，修改卡组名，保存后确认开局选项同步，使用新卡组进入对局。
- 844×390：完整卡组浏览器回归通过，页面没有横向溢出。
- 320×720：预设下拉框、导入按钮及名称框全部在工具栏内，无横向溢出。
- 1280×720：实际选择「速攻炎风」并修改名称，选择保持不变，怪兽摘要为正确基础数值，工具栏无溢出。
- 1920×1080：实际打开编辑器，确认桌面三栏及卡牌摘要显示；联机主要操作也在此尺寸验收。

### 双端联机：内置浏览器 + Chrome

使用独立本机测试服务 `--port=5180 --scenario=attack-chain-response`；测试账号写入忽略目录 `.tmp`，不使用玩家账号。两个页面在操作前均关闭音效。

1. 创建、加入同一房间，双方准备。
2. 1P 盖放断链裁决、召唤日冕骑士；有剩余行动时，结束回合先进入确认态，第二次确认后交给 2P。
3. 2P 盖放镜光反制并结束回合；1P 看见的是盖放卡，不暴露其名称。
4. 1P 发起直击，预览为 1700 伤害、对手 LP 4000 → 2300；取消后对手仍为 4000 LP。
5. 再次攻击，2P 发动镜光反制 CL1，1P 追加断链裁决 CL2。
6. 双方显示 `CL2 → CL1`，CL2 生效、CL1 被无效；骑士保留并已行动，双方一致显示仅扣除一次 1700 LP。
7. 1P 确认认输，2P 获胜；1P 发起再战，2P 显示「接受再战」，双方确认后进入第 2 局，由 2P 先手。
8. 刷新 1P，恢复原席位、第 2 局和 0 : 1 房间战绩，出现当前战况摘要，无历史攻击重播。
9. 结束第 2 局，双方房间战绩一致为 1 : 1。

## 体验反馈与下一步

- 卡组浏览仍以长列表为主；手机需要在多个区域间滚动。下一步建议增加按名称搜索与类型筛选，缩短找牌路径。
- 联机现有攻击预览、响应和再战路径本轮能够完成；联机自定义卡组、服务重启续局仍是后续功能，本轮未实现。
- 完整终局通过现有自动浏览器点击流程。本轮没有逐章人工通关全部六章，也没有覆盖全部卡牌组合、所有手机设备或弱网条件。
- 截图保留于本机忽略目录 `.tmp/playability-audit-1107/`，不提交测试账号、会话或浏览器存储。
