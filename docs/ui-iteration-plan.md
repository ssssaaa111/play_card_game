# 决斗 UI 迭代方向

## 当前判断

近期退化的核心不是单个尺寸，而是大屏布局由“一个战场”变成了多个彼此竞争的浮层。后续不再为每档屏幕追加一套独立摆法，而是维持同一套信息层级，只改变展示密度。

## P0：恢复战场主次关系

- 大屏将卡牌操作与战局时间线合并为一个中央指挥台，共享外框和间距。
- 当前卡牌与可执行操作放在左侧，最近战况和筛选放在右侧，避免两个独立面板争夺注意力。
- 4K 主舞台限制最大宽度，避免角色状态、回合操作和设置被拉到屏幕四角。
- 设置按钮统一尺寸；音量滑杆作为唯一的宽控件保留独立规格。
- 只有高度和宽度都足够时才常驻指挥台，其余尺寸继续使用抽屉。

## P1：提升场上卡牌可读性

- 统一怪兽、魔陷和手牌的视觉比例，减少同一张卡在不同区域的尺寸跳变。
- 强化可攻击、可选目标、不可用和当前选择四种状态，减少依赖说明文字。
- 让攻击预览贴近当前操作区，明确伤害、破坏和触发结果。

第一轮已落地：当前操作改用金色，可攻击保持青色，攻击目标使用红色，已行动与守备改用低干扰灰蓝；桌面和手机的怪兽状态轨道不再被裁切，非大屏攻击操作条会同步显示紧凑结算预览。下一轮继续统一魔陷与手牌比例。

第二轮已落地：宽屏工作台根据可用高度切换紧凑密度，避免 1700×1000 把场上怪兽压成缩略图；4K 手牌恢复接近场上卡牌的纵向比例，魔陷轨道、卡面与名称同步放大。下一轮进入阶段切换与关键战斗演出。

## P2：强化经典战役节奏

- 抽卡、主要、战斗和结束阶段使用更明确的舞台切换，而不是只更新顶栏文字。
- 关键召唤、连锁和 Boss 转阶段占据中央短时焦点，普通日志保持克制。
- 对手意图只展示公开信息，但要形成“蓄势、展开、反击”的连续叙事。

第一轮已落地：四个回合阶段现在由真实规则事件驱动舞台提示，快速交回合时按顺序播放，不会互相吞掉；提示层不接管点击，普通提示在转场期间自动让位，并已适配 4K、桌面、手机与减少动态效果。下一轮进入关键召唤和 Boss 转阶段演出。

## P3：建立统一视觉语言

- 收敛圆角、边框、阴影和强调色的规格，减少每个模块各做一套卡片。
- 明确金色用于当前行动、青色用于玩家信息、红色用于对手威胁、紫色用于连锁与陷阱。
- 动效服务于状态变化，去掉无信息价值的持续闪烁和重复光晕。

## P4：个性化与可访问性

- 提供紧凑、标准、沉浸三档密度，而不是继续增加分辨率特例。
- 支持字体放大、减少动态效果和高对比度。
- 保存玩家的 UI 密度、声音和面板偏好。

## 验收方式

- 每轮至少覆盖 3840×2160、2560×1440、1700×1000、1280×720 和 390×844。
- 浏览器真实点击验证选卡、攻击、取消、结束回合、暂停和抽屉开关。
- 自动检查面板不遮挡场地或手牌、直接设置可见、按钮尺寸一致。
