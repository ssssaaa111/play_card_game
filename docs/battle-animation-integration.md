# 战斗动画接入 V2

## 本轮行为
普通攻击和王牌攻击直接发生在棋盘的实际卡位之间，不再使用矩形攻击舞台。根据实体箭头的试玩反馈，恢复发光箭头、亮芯拖尾与交叉斩光。蓄势 140 ms、突进 105 ms、命中保持 70 ms，普通攻击约 660 ms、王牌约 750 ms。突进采用三次方加速，命中时短暂停顿并保留箭头轮廓，再快速消散，突出短促爆发。击破残影立即震开，约 180 ms 内消散，攻击者约 100 ms 收势，伤害数字迅速弹出并停留。受击闪亮绕过卡牌悬停过渡，演出结束或取消后还原；守备反击会向反方向击退攻击者。减少动态效果模式保持原有短流程。

- src/field-strike.js 管理透明 Canvas 和场上卡牌位移。攻击轨迹连接真实卡位，击破后的怪兽残影来自当前卡牌素材。
- 箭头恢复元素色外沿和白色内芯，基础箭头长 38 px、宽 32 px；配合多层发光拖尾。按攻击者卡牌尺寸缩放，王牌略微放大，避免直接攻击宽生命值面板时体积失控。撤下红橙色实体箭杆、挤宽与回缩动作。
- 陷阱响应先完成；取消攻击不会创建命中动画。响应 UI 可能重绘棋盘，出招前重新测量当前元素。
- 规则引擎只在命中回调中结算一次。同一回调更新战斗 LP、数字和音效调用；攻击后效果的 LP 另行展示。数字采用真实结算值，守住、反击、破防有对应结果标签。
- 蓄势到收势期间锁住下一步行动。暂停同时冻结待命中回调、动画帧和兜底计时器；重开取消旧攻击并清空暂存的 LP 显示。
- 帧调度停滞或 Canvas 故障时，兜底确保合法攻击只结算一次并释放行动锁。减少动态效果时改为约 330 ms 的简短结果提示。
- 效果层位于常规浮层和工具栏之上（150）；可交互模态窗保持更高层级（200）。模态窗出现时演出隐藏并暂停，关闭后恢复。效果层不接管指针。
- 出招时收起旧伤害预告；攻击期间隐藏重复的中央大字、吐司和对白浮层。最后一击完成收势后才安排胜负弹窗；重开使旧弹窗回调失效。
- 召唤和伤害魔法保留上一版独立演出，并加入模态窗暂停协调。下一步可继续打磨它们的动作与节奏。
- 保留手机唯一祭品确认栏位置修正，以及冒烟测试对自动选中唯一祭品的处理。
