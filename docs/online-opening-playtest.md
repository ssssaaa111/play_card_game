# 联机开局试玩基线

先手首回合禁战后，用三套固定牌表观察开局伤害和空过。基础与快攻取自当前预设，效果伤害组是 40 张合法自定义卡组。后续预设更新时仍可用这份[固定牌表](../scripts/fixtures/online-opening-decks.json)做同样对照。

| 简称 | 卡组 | 张数 |
| --- | --- | ---: |
| 基础 | 星魂基础扩展 01 | 42 |
| 快攻 | 速攻炎风 | 50 |
| 效果 | 炎岚效果伤害 | 40 |

效果组各放 3 张赤焰幼龙、疾风术士、预见之召、余烬星愿、爆裂符文、炎岚合击与星尘回收，保留[已知的 4400 伤害牌序](online-testing.md#可重复的陷阱实测)所需卡牌。该牌序已用这份固定牌表单独重现。

## 复跑

```powershell
node scripts/online-opening-playtest.mjs --games=100 --seed=opening-playtest-v1 --grave-return-trial
```

三种对局两边各跑 100 局，共 600 局。带 `--grave-return-trial` 时，命令按同一批种子输出不限次时的历史基线和限次后的结果。默认命令运行正式规则。每局使用联机房间校验卡组、洗牌、发牌和提交操作，每个座次使用可复现的洗牌。记录前 4 个游戏回合或提前结束的整局。统一操作策略优先抽牌、部署，再使用可用的效果伤害和陷阱，战斗只打预估占优的目标。牌组张数、操作策略与样本都可能影响结果。

首伤统计任一方第一次受到正数伤害的回合。开局掉血只累计先手首回合给后手造成的伤害，平均包含零伤害局。空过指该玩家完成自己的首回合，期间只切阶段或结束回合。对手回合的响应不计入该玩家的首回合行动，尚未交回合时已经结束的对局也不计入空过分母。

## 限次前基线

| 先手 → 后手 | 首伤在第 1 / 2 / 3 / 4 回合 / 无 | 后手行动前掉血局数 | 平均 / 最高掉血 | 先手 / 后手空过 |
| --- | --- | ---: | ---: | --- |
| 基础 → 快攻 | 17 / 66 / 7 / 4 / 6 | 17 | 34 / 200 | 0/100 · 0/95 |
| 基础 → 效果 | 13 / 77 / 1 / 5 / 4 | 13 | 26 / 200 | 0/100 · 0/100 |
| 快攻 → 基础 | 51 / 30 / 9 / 1 / 9 | 51 | 224 / 1000 | 0/100 · 0/100 |
| 快攻 → 效果 | 54 / 42 / 0 / 3 / 1 | 54 | 226 / 1000 | 0/100 · 0/98 |
| 效果 → 基础 | 78 / 10 / 8 / 0 / 4 | 78 | 533 / 1700 | 0/100 · 0/100 |
| 效果 → 快攻 | 71 / 26 / 2 / 1 / 0 | 71 | 531 / 2000 | 0/100 · 0/96 |

效果组先手时，149/200 局对手在行动前已掉血，均值 532，最高 2000。基础、快攻先手时分别为 30/200 局和 105/200 局。600 局随机样本里没有首回合胜利，固定牌序仍可通过效果斩杀。

## 浏览器实测

两套预设在本机真人房间 `AKXL7P` 实点换边。基础先手召唤天岚突袭者并盖下星魂格挡，快攻后手以装备锋刃刻印的日冕骑士攻击，预估 450 伤害。内置浏览器发动星魂格挡后，双方同步到 150 伤害、基础方 4150 LP。双方同房再战，快攻先手保留原卡组，禁攻状态下召唤星轨枪兵，基础方同步看到场面。

## 星尘回收限次对照

每位玩家同回合成功发动第一张星尘回收后，其他副本要等到下个自己的回合。该规则已接入联机房间，对照脚本和本机试玩场景沿用同一判定。

```powershell
node --test tests/online-grave-return.test.mjs
```

固定斩杀在限次前可以打到 0 LP。沿同一牌序启用限次后，首次回收仍可发动，第二次被服务端拒绝，后手以 600 LP 存活。把末两张回收替换为双重召唤和赤焰幼龙，同一副 40 张牌的另一个理想牌序可打至 400 LP。

同一效果的「星屑返轨」也可编入联机卡组。固定斩杀中用两张星屑返轨替换后两张星尘回收，仍可在第一次交回合前把后手打到 0 LP。房间测试复现了这条牌序。

600 个种子各跑限次前后一次，限次前的首伤、开局伤害和空过数据完全复现上表。

| 先手卡组 | 后手行动前掉血局数（限次前 → 限次后） | 平均开局掉血 | 最高开局掉血 | 掉血减少的局数 |
| --- | ---: | ---: | ---: | ---: |
| 基础 | 30 → 30 | 30 → 30 | 200 → 200 | 0/200 |
| 快攻 | 105 → 105 | 225 → 225 | 1000 → 1000 | 0/200 |
| 效果 | 149 → 146 | 532 → 493 | 2000 → 2000 | 17/200 |

其余 583 对开局的后手掉血相同。两组各有 535 局在前两回合出现首伤，随机样本中的首回合胜利和已完成首回合的空过均为 0。前四回合里，两组各有 231 局使用过回收，发动总次数从 348 降到 311，其中回收抽牌法术从 302 降到 267，回收伤害法术从 46 降到 44。第 3、4 回合的回收次数从 121 增至 144。当前自动操作策略偏重这两类目标，怪兽和陷阱的普通回收用真人场景验证。

浏览器试玩服务可用 `node scripts/duel-server.mjs --port=5266 --scenario=grave-return-limit` 启动。使用联机基础卡组进入固定场景，房主起手两张星尘回收，墓地有铁壁守卫和镜光反制。本轮在房间 `ND992T` 实点选择铁壁守卫并回收到手牌，第二张双击显示「次数用完」，刷新后保持限制。后手可在自己的回合取回铁壁守卫，原先手下一轮可用保留的第二张取回镜光反制。房间测试同时覆盖无效目标、重复确认、服务重启和直接提交第二张。

正式规则在隔离的 5267 服务复测，房间为 `J3GDGG`。手牌和详情显示限次文案，新局换先手后可正常发动。限次前的存档若已成功发动两次，恢复时保留已结算的两次，本回合第三张锁定，下个己方回合可以发动。
