# 联机开局试玩基线

先手首回合禁战后，用三套固定牌表观察开局伤害和空过。基础与快攻取自当前预设，效果伤害组是 40 张合法自定义卡组。后续预设更新时仍可用这份[固定牌表](../scripts/fixtures/online-opening-decks.json)做同样对照。

| 简称 | 卡组 | 张数 |
| --- | --- | ---: |
| 基础 | 星魂基础扩展 01 | 42 |
| 快攻 | 速攻炎风 | 50 |
| 效果 | 炎岚效果伤害 | 40 |

效果组各放 3 张赤焰幼龙、疾风术士、预见之召、余烬星愿、爆裂符文、炎岚合击与星尘回收，保留[已知的 4400 伤害牌序](online-testing.md#可重复的陷阱实测)所需卡牌。该牌序已用这份固定牌表单独重现。

## 复跑

```powershell
node scripts/online-opening-playtest.mjs --games=100 --seed=opening-playtest-v1
```

三种对局两边各跑 100 局，共 600 局。每局使用联机房间校验卡组、洗牌、发牌和提交操作，每个座次使用可复现的洗牌。记录前 4 个游戏回合或提前结束的整局。统一操作策略优先抽牌、部署，再使用可用的效果伤害和陷阱，战斗只打预估占优的目标。它用出牌方可见的信息作决定，适合比较同组开局指标。牌组张数、操作策略与样本都可能影响结果。

首伤统计任一方第一次受到正数伤害的回合。开局掉血只累计先手首回合给后手造成的伤害，平均包含零伤害局。空过指该玩家完成自己的首回合，期间只切阶段或结束回合。对手回合的响应不计入该玩家的首回合行动，尚未交回合时已经结束的对局也不计入空过分母。

## 本轮结果

| 先手 → 后手 | 首伤在第 1 / 2 / 3 / 4 回合 / 无 | 后手行动前掉血局数 | 平均 / 最高掉血 | 先手 / 后手空过 |
| --- | --- | ---: | ---: | --- |
| 基础 → 快攻 | 17 / 66 / 7 / 4 / 6 | 17 | 34 / 200 | 0/100 · 0/95 |
| 基础 → 效果 | 13 / 77 / 1 / 5 / 4 | 13 | 26 / 200 | 0/100 · 0/100 |
| 快攻 → 基础 | 51 / 30 / 9 / 1 / 9 | 51 | 224 / 1000 | 0/100 · 0/100 |
| 快攻 → 效果 | 54 / 42 / 0 / 3 / 1 | 54 | 226 / 1000 | 0/100 · 0/98 |
| 效果 → 基础 | 78 / 10 / 8 / 0 / 4 | 78 | 533 / 1700 | 0/100 · 0/100 |
| 效果 → 快攻 | 71 / 26 / 2 / 1 / 0 | 71 | 531 / 2000 | 0/100 · 0/96 |

效果组先手时，149/200 局对手在行动前已掉血，均值 532，最高 2000。基础、快攻先手时分别为 30/200 局和 105/200 局。600 局随机样本里没有首回合胜利，固定牌序仍可通过效果斩杀。现阶段先保留规则，下一轮用相同牌序对照「星尘回收同名每回合一次」和现行规则，比较首回合伤害与后续回收用途。

## 浏览器实测

两套预设在本机真人房间 `AKXL7P` 实点换边。基础先手召唤天岚突袭者并盖下星魂格挡，快攻后手以装备锋刃刻印的日冕骑士攻击，预估 450 伤害。内置浏览器发动星魂格挡后，双方同步到 150 伤害、基础方 4150 LP。双方同房再战，快攻先手保留原卡组，禁攻状态下召唤星轨枪兵，基础方同步看到场面。
