# 对局声音反馈

2026-09-22：统一恢复系统默认语音，只调整台词内容。

- 所有角色均使用浏览器和系统的默认中文语音，不指定男女声、音高、语速或音量，不再按事件混用不同声线。
- 三曜共降改为“日月星辰，听我号令。三曜，共降！”。逐神登场使用日、月、星各自的短宣言，去掉祭品数量、轮次等规则说明式台词。
- 普通召唤、魔法、陷阱、击破与直击台词缩短；详细规则仍在画面和记录中。召唤、魔陷及故事事件各保留一次语音入口。
- 神登场宣言由召唤入口朗读一次，随后剧情记录只更新文字，避免同一事件重复起声。

验证：音频调度、台词、卡牌数据、三曜规则和静态集成测试通过。在内置浏览器开启音效和语音，实际结束玩家回合触发完整对局的三曜共降，记录中出现新宣言、没有旧台词，控制台无错误。

人声仍由浏览器系统语音合成。本轮没有新增配音素材，也没有改变现有召唤与王牌提示音。
