# 卡组编辑器找牌

本轮独立基于主线 `d3b72a5`，不夹带上一轮尚未合入的服务续局提交 `39b32e6`，不调整战场布局、守备横置或卡牌规则。

## 功能

- 卡牌库支持卡名片段、效果文案和简短规则词（例如“抽牌”）搜索，空格分隔的多个关键词同时匹配；英文 ID 忽略大小写，兼容全角输入。不把用户输入当正则表达式。
- 搜索可与“全部 / 怪兽 / 魔法 / 陷阱”组合，显示匹配种类数和无结果提示。一键清除同时重置搜索与类型，并把焦点还给搜索框。
- 加减卡、改名、导入和保存不会清掉筛选条件；当前筛选不变时保留卡牌库滚动位置。无结果不会改变草稿、合法性或保存状态，同名卡 3 张上限继续生效。
- 真实桌面验收额外发现原有大屏战场样式会隐藏编辑器关闭按钮。只对编辑器头部恢复 44×44 的关闭按钮，未修改战场抽屉的显示规则。
- 未筛选的长列表原本还存在桌面网格行按内容撑高、再被外层裁切的问题。编辑器桌面行改为可收缩轨道，使草稿和卡牌库各自在栏内滚动；手机仍保持原有纵向分栏。实际滚到末尾加减卡，卡牌库滚动位置保持不变。

## 验收

- 卡组视图测试 13 项通过，其中新增 6 项覆盖组合搜索、效果词、多关键词/全角、清除、无结果不改草稿和数量上限。
- 全量 1177 项测试通过（本分支不含上一轮独立续局分支的测试）。
- 现有 `custom-deck-editor-basic` 回归扩展为搜索、加到第 3 张、保留条件、无结果、清除焦点、效果词、筛选中导入，再完成原有编辑、保存、开局和完整卡组集合校验。
- 同一流程增加 `custom-deck-editor-desktop`，在现有浏览器 CI 集合中覆盖大屏关闭按钮；没有新增 CI 任务。预览、手机卡组浏览、手牌整理相关回归也通过。
